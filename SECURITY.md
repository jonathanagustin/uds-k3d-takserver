# Security Policy

## Supported versions

This package has not reached v1.0.0. Only the latest revision on the default branch is supported.

## Reporting a vulnerability

Report it privately through GitHub's private vulnerability reporting:
<https://github.com/jonathanagustin/uds-k3d-takserver/security/advisories/new>

Do not open a public issue for a vulnerability.

Include the affected version or commit, the component (TAK images, CloudTAK image, Zarf package, chart, Pepr module, or CI), steps to reproduce, and the impact you expect.

## What to expect

- A first response within 14 days of the report.
- An assessment and, if confirmed, a fix plan or mitigation within 90 days. Fixes ship in a new release and the advisory is published after the fix is available.
- Report vulnerabilities in TAK Server or CloudTAK code to those projects. This repository picks up their fixes.
