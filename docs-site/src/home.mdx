Use this package to run TAK Server and CloudTAK on UDS Core. TAK Server connects field clients; CloudTAK provides the browser map.

- **TAK Server:** API, enrollment, and streaming endpoints for certificate-based clients.
- **CloudTAK:** A browser map with Keycloak sign-in.
- **UDS integration:** Reuses Core's identity services, gateways, and default-deny network policies.

Start with [Getting started](/uds-k3d-takserver/getting-started/) to deploy a release or build a local test environment.
