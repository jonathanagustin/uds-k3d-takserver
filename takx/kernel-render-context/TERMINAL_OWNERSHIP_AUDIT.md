# Terminal ownership source audit

Source reasoning only; native runtime qualification remains pending. Exact official preimages and changed postimages are in source-scope.json.

GLLabelManager.owner and ElMgrTerrainRenderService.owner strongly retain GLMapView. Built-in inner controls and the context-control closure retain it too. Native renderer marshal and camera-forwarder registrations use weak Java references. Terminal disposal therefore does not manually run the renderer cleaner. The cleaner preserves the removed Globe reference through native destruction, protecting GLGlobe.view during final detach/listener removal.

Stop detaches model/layer producers and stops terrain workers. Release requires the old owning GL context current. Previously accepted Java work drains before native retirement. Retirement establishes both worker barriers before callbacks, drains within its soft bound, closes submission and preempts unfinished Work with TE_Canceled outside locks. Cancellation continuations drain before cache cleanup. Held old workers stay closed after rebind. Quiescing rejects new external work while owned current-thread cleanup can finish.

GLGlobeBase releases layer/label/managed basemap GPU resources. GLGlobe releases surface megatextures, private atmosphere program/textures/buffers, terrain VBO/IBO ownership, cull FBO/PBOs and depth FBO, resetting borrowed terrain shader/white-pixel snapshots. Scoped cleanup visits all former thread cache slots: native text/fixed/shader, batch shaders/atlases, terrain/slope/heat, Cesium and Java text/shader/image/raster resources. Renderer3 joins its old builder and destroys ready UV/texture bookkeeping before atlas recreation, cancelling pending futures. Registry locks are not held across GL or callbacks. External sprite sheets remain caller-owned.

After real stop/GPU release, terminal disposal breaks managed basemap/stars cycles and marks the native renderer while still current. Later GLGlobe destruction performs CPU detach and terrain stop. Terminal Base stop skips refreshLayers scheduling against the dead context. TiledGlobe.stop signals CPU monitors, clears requests and joins workers, with no GL. Surface renderer and megatexture destructors are empty. Atmosphere private program was reset during release. Already-released zero-handle FBO destruction skips GL. Base destroys its label manager before erasing the terminal marker; label stop is empty in this source. It invalidates asynchronous CPU state and erases the marker last, preventing a reused renderer address from inheriting terminal status.

This does not reclaim all caches. Binding/font/shader CPU identities are retained for process lifetime, with no fixed bound across unlimited contexts/fonts. Raw-texture GLImage instances reject stale use and require caller recreation. Shared main contexts and external resources remain unsupported gates. The prepared headed probe separately retains each real borrowed family, checks safe terminal calls, then awaits weak owner collection and a native destructor-counter advance without manual cleaner calls. That counter is aggregate evidence, never a freed-pointer dereference. No rebuilt feature GL/GC control has run. Native ABI/descriptors, provider closure, zero JNI warnings, actual pixels and normal process shutdown remain required.
